# Airport Flight Data Analysis — Python

## Project Overview
A Python-based airport flight data analysis application developed as part of my Software Engineering studies at the University of Westminster.

The project focuses on processing flight datasets, calculating statistics and presenting results through graphical visualisations.

## Key Features
- Reads and processes airport flight data from CSV files.
- Validates user input for airport codes and years.
- Calculates flight statistics, including delays, airlines and destinations.
- Generates graphical histograms using Python's graphics.py library.
- Saves analysis results to a text file.
